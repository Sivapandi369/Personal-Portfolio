# Sivapandi R - Software Developer Portfolio

A highly modern, responsive portfolio web application created for **Sivapandi R**. It transforms the traditional static resume into an interactive digital showcase with dark/light mode toggles, scroll animations, direct PDF resume downloading, and full mobile responsiveness.

---

## 🌟 Key Features

1. **Clean White Theme (Default)**
   - Ultra-neat, crisp, professional white background theme with subtle indigo/azure gradient accents and sleek card layouts.
2. **Dark Mode Toggle**
   - Instant Dark/Light theme switching with automatic system preference detection and `localStorage` state persistence.
3. **Scroll Reveal Animations & Progress Indicator**
   - Smooth `IntersectionObserver` scroll animations for elements, animated skill progress bars, and top scroll progress tracker.
4. **Downloadable PDF Resume**
   - Built-in "Resume PDF" button that generates and downloads a clean 1-page PDF document using `html2pdf.js`.
5. **Interactive Project Showcase**
   - Modal popups for project details ("Personal Portfolio Website" and "Student Management System").
6. **One-Click Contact & Copy-to-Clipboard**
   - Clickable contact pills for Phone (+91 9360833565) and Email (sivapandi622004@gmail.com) with toast confirmation feedback.
7. **Complete Source Code (.ZIP)**
   - Pre-packaged ZIP archive containing all project files.

## 🚀 How to Run Locally

1. Download and extract `sivapandi_portfolio.zip`.
2. Open `index.html` directly in any web browser (Google Chrome, Microsoft Edge, Firefox, Safari).
3. Alternatively, launch with Live Server or `npx serve .`.
